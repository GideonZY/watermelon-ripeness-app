# 挑个好西瓜 Android App

**本项目所有代码由 ChatGPT 协助完成，项目目标是让普通用户用手机麦克风辅助挑选西瓜。**

v0.3.0 将 0.2.x 的“单一主频阈值演示”升级为“三次有效拍击 + 多声学特征 + 一致性检查”的文献启发式方案。用户点击开始检测后，App 以 100 ms 周期实时分析拍击声；仪表盘只负责给出即时声音反馈，最终的购买建议不会只看某一个 Hz。

> 重要：当前算法有文献依据，但本项目尚未拥有足够的真实切瓜标注数据完成参数校准，因此不能把结果当作食品质量保证或商业分级结论。

## v0.3.0：挑个好西瓜

### 面向购买场景的 UI

- 首页标题改为 **“挑个好西瓜”**。
- 首页只告诉用户三件事：靠近西瓜中部、连续轻拍三下、等待购买建议。
- 不在首页展示频谱质心、RMS、衰减等技术术语。
- 点击开始后才显示实时仪表盘；100 ms 刷新一次。
- 不显示“1/3、2/3、3/3”。有效拍击通过仪表盘的明显跳动和短暂脉冲反馈。
- 检测结束后收起仪表盘，按钮下方直接显示大号结论：
  - **推荐购买 · 适熟**
  - **不建议购买 · 偏生**
  - **不建议购买 · 偏熟**
  - **建议重新检测**（拍击不足或结果不稳定）
- 音频全程只在内存中处理，不生成 WAV，不写入手机存储。

### 为什么改成三次拍击

手机实际使用时，单次拍击容易受力度、位置、环境噪声影响。v0.3.0 后台自动识别三次明显的瞬态拍击；第三次拍击后再保留约 200 ms 尾音用于衰减分析，然后自动结束。最长等待时间为 5 秒。

用户可以正常快速连续拍，不需要盯着次数提示。

## v0.3.0 算法

当前实现是**文献启发的可解释启发式算法**，不是已经训练完成的机器学习模型。

每次有效拍击会提取：

- 主共振频率；
- 频谱质心；
- 80–220 Hz 低频能量占比；
- 拍击后的衰减 dB；
- 拍击信噪比。

公开研究较一致地表明：随着西瓜从未熟向过熟发展，共振/平均频率总体向低频移动；瞬态声的衰减特征也会发生规律变化。共振频率与果肉硬度、弹性特性存在显著关系。同时，品种、拍击位置和力度会显著影响绝对数值，因此 v0.3.0 不再使用“某一个固定 Hz 直接决定成熟度”的方式。

三次拍击分别形成 0–1 的内部成熟度指数，再取中位数综合。若三次主频差异过大、成熟度指数跨度过大或平均信噪比过低，则直接要求重新检测，不强行猜结果。

### 当前工程参数

参数统一集中在 `LiteratureHeuristicClassifier.kt` 中，后续拿到真实西瓜数据后可以重新拟合，而无需重写 UI 和录音流程。

当前主要权重：

- 共振频率：60%
- 衰减特征：22%
- 低频能量占比：13%
- 频谱质心：5%

这些权重和边界是基于公开研究趋势设置的**第一版工程起点**，并非论文直接给出的通用参数。

## 参考研究方向

- Li Y. 等，2025，*Factors influencing watermelon ripeness classification using acoustic signals collected via mobile phones*：手机采集条件下，品种、采集部位、力度均会影响分类；西瓜赤道/中部区域区分效果最好。
- Li Y. 等，2025，*Transient sound signal analysis for watermelon ripeness detection using HHT and NMF*：从未熟到过熟平均频率总体下降、衰减速率增加；多特征处理明显优于简单分类。
- Mao J. 等，2016，*Firmness prediction and modeling by optimizing acoustic device for watermelons*：共振频率及频谱相关指标与西瓜果肉硬度显著相关。

因此 App 的操作提示统一要求尽量拍击**西瓜中部/赤道区域**，并保持相近力度。

## 使用方法

1. 把手机麦克风靠近西瓜中部约 10–20 cm。
2. 点击 **开始检测**。
3. 用相近力度连续轻拍西瓜三下，不用等待屏幕提示。
4. 有效拍击时实时仪表盘会明显响应。
5. App 自动结束后给出购买建议；如果提示结果不稳定，请保持相同位置和力度重新检测。

## 下一阶段：真实数据校准

0.3.0 解决了“算法结构”的问题，但真正决定准确率的是数据。建议后续建立真实样本集：每个西瓜检测后切开，记录品种、重量、Brix 糖度、果肉硬度、空心/糠心和人工口感标签。训练/测试划分必须按“瓜”进行，不能把同一个瓜的多次拍击随机分到训练集和测试集。

有足够数据后可以：

1. 重新拟合当前多特征权重和阈值；
2. 用逻辑回归、随机森林或 SVM 做可解释基线；
3. 再评估 HHT/NMF 或 log-mel + 小型 CNN；
4. 最终导出 TensorFlow Lite 模型，在手机本地推理。

## 已知限制

- 不同西瓜品种的声学分布可能不同；公开研究显示品种是重要影响因素。
- 敲击位置和力度会影响结果，因此建议始终拍击瓜体中部并保持相近力度。
- 手机麦克风和系统音频处理可能产生设备差异，需要多机型真机验证。
- 当前多特征权重尚未用本项目真实切瓜数据校准。
- `UNPROCESSED` 音源在部分手机上的支持情况需要继续测试。
